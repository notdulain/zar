# PR #18 review evidence

The PNGs in this folder are captured from the running debug app on the Pixel 6a emulator by `CatchUpUiTest`, after the review changes. They use fixed sample data and render the real Compose screens. They cover Needs review (items and empty), review/first catch-up/count/save/done, shortfall/surplus/match/offline/error states, reminder on/off/skipped/notifications blocked, the move sheet, and the native custom time picker. The original screenshots one folder above are historical evidence from the author and predate the styling review.

Compared with the Zar UI Figma file `bBBJuQz1Cg8N34FcisKBs9`, section `323:4398`, frames Z73–Z85. The review uses the app's shared Geist typography, buttons, chips, cards and theme tokens. The compact review rows, stacked 34sp count field, 12dp note cards, matching icons, neutral/navy time dialog and saved-adjustment action follow those frames. Shared app card elevation and native system bars/picker controls are retained. Dates, account names and amounts come from fixtures rather than Figma placeholders. “Leave for later” is represented by leaving an entry unresolved; no redundant write is added.

The five new transparent Android density icons are unmodified Figma Phosphor Regular exports rasterized to 128×128 PNG (xxxhdpi): Coins (`1:13050`, shown in `324:4476`), Question (`1:5163`, `323:4399`), CheckCircle (`1:13679`, `324:4579`), ListChecks (`1:8081`, `327:4729`), BellSlash (`326:4584`). They render through the shared icon components at the frame's 19dp/20dp sizes, inside 40dp chips where appropriate. No temporary Figma URL is used by the app.

Review fixes also exclude future cash movements/opening dates from the current count, include missing-rate refunds in Needs review, retain an uncertain save's confirmed amount and ID for retry, close rather than edit that attempted catch-up, show reminder write/skip failures, serialize rapid reminder edits against persisted settings, and preserve pending notification navigation through activity recreation. Before the first save attempt, Back still returns to counting.

Verification: 502 unit tests, debug build and Android lint pass. The emulator run covers the catch-up UI, Home review entry point, and the real WorkManager worker posting a notification, queuing its successor and respecting the off setting. See the PR description for the final test count. No live Firebase project was used by this review. Existing local-ledger cash reconciliation is not a server-serialized operation across independently offline devices. WorkManager reminders are approximate; exact delivery at the selected wall-clock time and a physical device were not tested.
